# Waypoint – Youth Mountain Biking Training Hub

A user-centered web application designed to help competitive youth mountain bikers **organize training, set goals, track progress, and stay connected with their team**.

The concept was developed through a team-based HCI design process using interviews with real youth mountain bikers. Our research informed **user personas, journey maps, prototypes, and design iterations**. Following the collaborative design process, I **independently developed the website from scratch** using HTML, CSS, and JavaScript.

## Design Process

* Conducted interviews with youth mountain bikers
* Identified user needs, behaviors, and pain points
* Developed user personas and journey maps
* Created and iterated on prototypes based on research findings
* Translated the final design concepts into a functional web application

## Key Features

* **Training Plan** — View daily activities and track completion
* **Waypoints** — Create and track smaller goals toward larger season goals
* **Progress & History** — View training statistics and past activities through an interactive calendar
* **Team Hub** — Access coach updates, teammate shoutouts, and practice and race schedules
* **Trail Weather** — Check current weather and riding conditions for practice and race locations

## Technologies & Skills
